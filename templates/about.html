About This Tool

Project Overview

This Mental Health Risk Prediction tool was developed using anonymized population health data from the New York City Office of Mental Health (NYC OMH). It uses supervised machine learning to predict whether an individual is at risk of mental illness based on 33 demographic, socioeconomic, and clinical features.

Models

Model Type Description
Random Forest Ensemble High-accuracy ensemble of decision trees with hyperparameter tuning via GridSearchCV.
Decision Tree Tree Interpretable single-tree model, useful for understanding decision logic.
Logistic Regression Linear Baseline linear classifier; fast and interpretable with probability calibration.
Neural Network (MLP) Deep Learning Multi-layer perceptron with hidden layers trained on the same feature set.

Data & Features

Training data was sourced from the NYC OMH public dataset. Features cover age, household composition, education, employment, housing, insurance status, chronic conditions, substance use, criminal justice involvement, and more. The target variable is a binary indicator of mental illness diagnosis.

Limitations & Disclaimer

This tool is for research and educational purposes only.

  • Predictions reflect statistical patterns in historical data and may not apply to every individual.
  • The model was trained on NYC population data; generalisability to other populations is not guaranteed.
  • Never use this output as a substitute for a professional clinical assessment.
  • Results should be interpreted by qualified mental health professionals.
